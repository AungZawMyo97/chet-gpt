# API Specification: `POST /api/recipes`

The Chet-GPT server handles recipe requests through a robust API endpoint that validates incoming parameters, enforces payload size restrictions, and orchestrates the generation engine.

## Endpoint Overview

* **URL**: `/api/recipes`
* **Method**: `POST`
* **Content-Type**: `application/json`

---

## Security & Payload Restrictions

To prevent server overload and API abuse, the endpoint enforces several constraints:

| Constraint | Maximum Allowed | Failure Action | HTTP Code |
| :--- | :--- | :--- | :--- |
| **Request Size** | `8,192 bytes` (8 KB) | Returns error "Request is too large." | `413 Payload Too Large` |
| **Content-Type** | Must include `application/json` | Returns error "Request must be JSON." | `415 Unsupported Media Type` |
| **Text Length** | `500 characters` for `ingredients` text | Returns error "Ingredients text is too long." | `413 Payload Too Large` |
| **Missing Ingredients**| Empty list after regex parsing | Returns error "Please add at least one ingredient." | `400 Bad Request` |
| **Malformed JSON** | Parser exceptions | Returns error "Invalid JSON request." | `400 Bad Request` |

---

## Request Body

The request body must be a JSON object containing the following keys:

```json
{
  "ingredients": "ကြက်သား၊ ကြက်သွန်နီ၊ ခရမ်းချဉ်သီး",
  "style": "quick",
  "model": "google/gemma-4-26b-a4b-it:free"
}
```

### Parameters

* **`ingredients`** (Required `string`):
  A comma-separated, semicolon-separated, or newline-separated list of ingredients.
* **`style`** (Optional `string`):
  Desired cooking style. Must be one of the normalized styles: `"any"`, `"quick"`, `"family"`, `"spicy"`, `"healthy"`, `"budget"`. Defaults to `"any"` if omitted or invalid.
* **`model`** (Optional `string`):
  Requested AI model identifier (e.g. `"gemini-2.5-flash"`, `"gemini-2.5-pro"`). Forwarded to Google Gemini during recipe generation. If missing or offline, defaults to the pre-configured environment model.

---

## Response Schemas

### 1. Success Response (`200 OK`)

Returns a recipe suggestion bundle. The suggestions are either freshly generated by the Google Gemini AI provider or compiled by the offline fallback generator.

```json

    {
      "id": "home-style-curry",
      "title": "အိမ်ချက်ဆီပြန်ဟင်း",
      "burmeseTitle": "ကြက်သား ဆီပြန်ဟင်း",
      "summary": "ကြက်သွန်နီအခြေခံပြီး နနွင်းနံ့သင်းသင်းနဲ့ ထမင်းမြိန်စေတဲ့ အိမ်ချက်ဟင်းပါ။",
      "cookTimeMinutes": 35,
      "difficulty": "Easy",
      "matchingIngredients": ["ကြက်သား", "ကြက်သွန်နီ"],
      "missingIngredients": ["ဆီ", "ဆား", "ကြက်သွန်ဖြူ"],
      "steps": [
        "ကြက်သွန်နီ၊ ကြက်သွန်ဖြူနဲ့ ရှိတဲ့ဟင်းသီးဟင်းရွက်တွေကို ပါးပါးလှီးပါ။",
        "ဆီနည်းနည်းနဲ့ ကြက်သွန်နီ၊ နနွင်း၊ ဆားကို နူးအောင်ဆီသတ်ပါ။",

        "ရေနည်းနည်းထည့်ပြီး အဖုံးအုပ်ကာ နူးတဲ့အထိ တည်ပါ။",
        "အရသာညှိပြီး ငရုတ်သီး သို့မဟုတ် နံနံပင် ရှိရင် အပေါ်က ဖြူးပါ။"
      ],
      "tips": [
        "ရေနည်းနည်းနဲ့တည်ရင် ဟင်းရည်ပိုစေးပြီး ထမင်းမြိန်ပါတယ်။",
        "ချဉ်ပေါင်ဟင်းချို သို့မဟုတ် အချဉ်သုပ်တစ်ခုနဲ့ တွဲစားလို့ကောင်းပါတယ်။"
      ]
    }
  ],
  "source": "local",
  "note": "AI key မရှိသေးလို့ အနီးစပ်ဆုံး ဟင်းအကြံပြုချက်တွေကို ပြထားပါတယ်။"
}
```

#### Fields Breakdown

* **`recipes`** (`array`): A list of up to 3 recipe suggestion items.
  * **`id`** (`string`): Web-safe kebab-cased unique identifier.
  * **`title`** (`string`): English or descriptive Burmese title of the recipe.
  * **`burmeseTitle`** (`string`): Main Burmese name of the meal.
  * **`summary`** (`string`): Brief recipe overview.
  * **`cookTimeMinutes`** (`number`): Suggested cook time bounded between 5 and 240 minutes.
  * **`difficulty`** (`string`): One of `"Easy"`, `"Medium"`, `"Hard"`.
  * **`matchingIngredients`** (`string[]`): Ingredients from the request that fit this recipe.
  * **`missingIngredients`** (`string[]`): Supplemental items (e.g., pantry basics) recommended to complete the recipe.
  * **`steps`** (`string[]`): Numbered sequential instructions in Burmese.
  * **`tips`** (`string[]`): Helpful advice for optimal results.
* **`source`** (`string`): `"ai"` if populated by Google Gemini, `"local"` if generated by the fallback module.
* **`note`** (`string`, optional): Addtional status details (e.g., fallback warning message).

### 2. Error Response (`400`, `413`, `415`, `500`)

Returned if validation fails or an unhandled processing exception occurs.

```json
{
  "message": "Please add at least one ingredient."
}
```

## Route Processing Logic

Inside `src/app/api/recipes/route.ts`:
1. **Size check**: Measures `content-length` to block payloads above 8KB immediately.
2. **Header check**: Verifies client sent `application/json`.
3. **JSON parsing**: Gracefully catches parsing errors.
4. **Length limit check**: Restricts ingredient input to 500 characters.
5. **Ingredient splitting**: Extracts valid terms using `parseIngredients` domain logic.
6. **Generator selection**: 
   * Reads `process.env.GEMINI_API_KEY`.
   * If present, initializes `GoogleGeminiRecipeGenerator` wrapping the local generator as a fallback.
   * If absent, directly initializes `LocalRecipeGenerator`.
7. **Use Case Execution**: Triggers `GenerateRecipesUseCase` within clean domain confines.
